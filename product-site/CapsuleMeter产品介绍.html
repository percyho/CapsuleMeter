你的 Codex 用量，
一眼尽收

功能特性

为桌边常驻而设计

无边框贴边吸附

按住任意位置拖动，自动贴向屏幕四边四角、避开任务栏，重启后记住位置。

自动刷新

默认每 5 分钟从 OpenAI 后端拉取最新用量，间隔可在 1～30 分钟间自定义。

低额度通知

剩余触及 10% / 20% / 30% 阈值时推送通知，阈值可开关，不必时时盯着。

全局快捷键

默认 Ctrl+Shift+U 一键显示或隐藏胶囊，可在系统设置中录制新组合键或停用。

用量历史图表

独立的 920×600 使用历史窗口，额度折线图与 Token 柱状图，支持导出 CSV。

限额重置

显示可用重置次数与到期时间，经二次确认后重置每周与 5 小时限额。

用量历史

不只看到当下，还能回看趋势

从“统计”标签打开使用历史窗口，额度与 Token 两个维度分别追踪，本地保留周期可设 7 / 30 / 90 / 365 天。

隐私承诺

  • 令牌仅在本机 —— 访问 / 刷新 / ID 令牌只由本地 Rust 后端使用，绝不暴露给前端或第三方。
  • 仅显示账号邮箱 —— 只从 ID 令牌本地解析邮箱用于显示，不含其他敏感信息。
  • 历史记录只在本地 —— 额度采样本地保存，可一键导出，也可随时清除。
